# ひらがな あいうえお

3歳児が自分で触って遊べる、ひらがな五十音表のアプリ。
マスをタップすると、その文字ではじまる絵が跳ねて、ことばの音声が鳴ります。

フェーズ1 は **あいうえお + かきくけこ + おまけの「ん」= 11マス**。

公開先: https://sakanayuki.github.io/cc_hiragana/

## あそびかた

| モード | 内容 |
| --- | --- |
| **あそぶ**（既定） | 表を自由にタップ。絵が跳ねて、ことばが鳴り、画面いっぱいにその文字が出ます。連打しても必ず最新のタップが鳴ります。 |
| **クイズ** | 上に出た大きなひらがなと同じマスを表から探します。5問で1セット。まちがえても減点なし、2回まちがえると正解のマスがそっと光ります。 |

モードの切り替えは、**右上の歯車を 1.2 秒長押し**。子どもが誤って触っても切り替わらないようにしてあります。

## 素材の対応

| # | 絵 | かな | ことば | 音声 | クイズ |
| --- | --- | --- | --- | --- | --- |
| 1 | あり | あ | あり | `a.mp3` | ○ |
| 2 | いぬ | い | いぬ | `i.mp3` | ○ |
| 3 | うし | う | うし | `u.mp3` | ○ |
| 4 | えんぴつ | え | えんぴつ | `e.mp3` | ○ |
| 5 | おにぎり | お | おにぎり | `o.mp3` | ○ |
| 6 | かめ | か | かめ | `ka.mp3` | ○ |
| 7 | きりん | き | きりん | `ki.mp3` | ○ |
| 8 | くるま | く | くるま | `ku.mp3` | ○ |
| 9 | けいと | け | けいと | `ke.mp3` | ○ |
| 10 | こま | こ | こま | `ko.mp3` | ○ |
| 11 | うんち | ん | うんち | `un.mp3` | **×** |

「ん」だけはクイズに出しません。音声が「うんち」（う からはじまる）で、
文字と音の頭がそろわず子どもが混乱するためです。表には常に出るので、
触れば「ん」の拡大表示と「うんち」の音声が鳴ります。

## 開発

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 型チェック + dist/ 生成
npm run preview    # 本番ビルドの確認
```

### 絵の切り出し

`assets-source/aka.jpeg` は 4×4 のスプライトです。番号・タイル背景・枠を取り除いて
背景透過 PNG に切り出すのが `tools/slice_sprite.py` です。
**生成物は `public/icons/` にコミット済み**なので、通常は実行不要です。
素材を差し替えたときだけ実行してください。

```bash
python3 -m pip install pillow numpy
npm run slice
```

実行すると `tools/out/contact-sheet.png` も出ます。
11枚すべてで「番号が消えている」「背景が抜けている」「絵が欠けていない」を目視で確認してください。

## 五十音を増やすには

1. 新しい絵のスプライトを `assets-source/` に置き、`tools/slice_sprite.py` の `TILES` に追記して実行
2. mp3 を `assets-source/audio/` と `public/audio/` に追加
3. `src/data/characters.ts` の `CHARACTERS` に行を追加し、`KANA_ROWS` に行（`'sa'` など）を追加

レイアウトは `KANA_ROWS` の数から自動で組まれます。ただし縦持ちは列が増えるほど
1マスが小さくなるため、さ行以降を足すときは横スクロールかページ送りの検討が必要です。

## 技術メモ

- **Vite + TypeScript**（フレームワークなし）。ビルド成果物は静的ファイルのみ。
- **音声は Web Audio API**。`<audio>` は再生開始が遅く、連打時に前の音を止められないため使っていません。11ファイルを起動時に一括デコードして持ちます。
- **効果音は `OscillatorNode` で合成**（`src/audio/sfx.ts`）。音声ファイルを増やさずオフラインでも鳴ります。
- **入力は `pointerdown`**。`click` は 100〜300ms 遅れ、3歳児には反応が鈍く感じられます。
- **レイアウトは CSS のみで切り替え**。各マスが縦持ち用・横長用の座標を両方持っているので、端末を回した瞬間に JS を介さず並び替わります。
- **PWA**（`vite-plugin-pwa`）。絵と音を含めて全アセットをプリキャッシュするので完全オフラインで動きます。
- **子ども防御**: ピンチ／ダブルタップ拡大、長押しメニュー、テキスト選択、ドラッグ、2本指スクロールをすべて無効化。外部リンクは 0 個。

## デプロイ

`main` への push で `.github/workflows/deploy.yml` が走り、GitHub Pages に公開されます。

配信方式（Settings → Pages → Source）の切り替えはワークフロー側で行います
（`actions/configure-pages` の `enablement: true`）。手動設定は不要です。
