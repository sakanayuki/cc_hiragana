# ひらがな あいうえお

3歳児が自分で触って遊べる、ひらがな五十音表のアプリ。
マスをタップすると、その文字ではじまる絵が跳ねて、ことばの音声が鳴ります。

収録は **あ行〜た行（あいうえお・かきくけこ・さしすせそ・たちつてと）+ おまけの「ん」= 21マス**。

公開先: https://sakanayuki.github.io/cc_hiragana/

## あそびかた

| モード | 内容 |
| --- | --- |
| **あそぶ**（既定） | 表を自由にタップ。絵が跳ねて、ことばが鳴り、画面いっぱいにその文字が出ます。連打しても必ず最新のタップが鳴ります。 |
| **クイズ** | 上に出た大きなひらがなと同じマスを表から探します。5問で1セット。まちがえても減点なし、2回まちがえると正解のマスがそっと光ります。 |

モードの切り替えは、**右上の歯車を 1.2 秒長押し**。子どもが誤って触っても切り替わらないようにしてあります。

## 開発

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 型チェック + dist/ 生成
npm run preview    # 本番ビルドの確認
```

### 絵の切り出し

`assets-source/aka.jpeg` と `sata.jpeg` は 4×4 のスプライトです。番号・タイル背景・枠を
取り除いて背景透過 PNG に切り出すのが `tools/slice_sprite.py` です。
**生成物は `public/icons/` にコミット済み**なので、通常は実行不要です。
素材を差し替えたときだけ実行してください。

```bash
python3 -m pip install pillow numpy
npm run slice
```

実行すると `tools/out/contact-sheet.png` も出ます。
21枚すべてで「番号が消えている」「背景が抜けている」「絵が欠けていない」を目視で確認してください。

## 五十音を増やすには

1. 新しい絵のスプライト（1024x1024 の 4x4）を `assets-source/` に置き、
   `tools/slice_sprite.py` の `SHEETS` にブロックを 1 つ追加して `npm run slice`
2. mp3 を `assets-source/audio/` に置き、`public/audio/` へコピー
   （`cp assets-source/audio/*.mp3 public/audio/`）
3. `src/data/characters.ts` の `CHARACTERS` に行を追加し、`KANA_ROWS` に行名を追加

**レイアウトと配色以外の改修は不要です。** 盤面の列数・行数は `KANA_ROWS` の数から
自動で組まれます（`Board.ts` が `--row-count` を CSS に渡し、`board.css` がそこから
1 マスの大きさを算出）。新しい行の色だけ `base.css` の `--{行}-face` / `--{行}-edge` と
`board.css` の `.cell[data-row='{行}']` に足してください。

通し番号は五十音順で、「ん」はおまけなので末尾（21）に固定しています。行を足すときは
「ん」の番号を最後尾へずらすと、`public/icons/` が五十音順に並んで見やすくなります。

### 増やすほどマスは小さくなります

1 画面に必ず収める設計なので、行が増えると 1 マスは小さくなります。実測値:

| | 縦持ち 390x844 | 横持ち 1024x768 | 横持ち 667x375 |
| --- | --- | --- | --- |
| 11マス（あ・か） | 144px | 191px | 127px |
| 21マス（あ〜た） | 90px | 152px | 74px |

な行以降まで伸ばすなら、横スクロールかページ送り（行ごとにめくる）への
切り替えを検討してください。

## 技術メモ

- **Vite + TypeScript**（フレームワークなし）。ビルド成果物は静的ファイルのみ。
- **音声は Web Audio API**。`<audio>` は再生開始が遅く、連打時に前の音を止められないため使っていません。21ファイルを起動時に一括デコードして持ちます。
- **効果音は `OscillatorNode` で合成**（`src/audio/sfx.ts`）。音声ファイルを増やさずオフラインでも鳴ります。
- **入力は `pointerdown`**。`click` は 100〜300ms 遅れ、3歳児には反応が鈍く感じられます。
- **レイアウトは CSS のみで切り替え**。各マスが縦持ち用・横長用の座標を両方持っているので、端末を回した瞬間に JS を介さず並び替わります。列数・行数は `--row-count` から算出しているので、行を足しても CSS は無改修です。
- **PWA**（`vite-plugin-pwa`）。絵と音を含めて全アセットをプリキャッシュするので完全オフラインで動きます。
- **子ども防御**: ピンチ／ダブルタップ拡大、長押しメニュー、テキスト選択、ドラッグ、2本指スクロールをすべて無効化。外部リンクは 0 個。

## デプロイ

`main` への push で `.github/workflows/deploy.yml` が走り、GitHub Pages に公開されます。

配信方式（Settings → Pages → Source）の切り替えはワークフロー側で行います
（`actions/configure-pages` の `enablement: true`）。手動設定は不要です。
